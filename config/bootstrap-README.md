# Popularia Control

Projeto de controle criado pelo deploy `popularia-autopilot`.

Use o cockpit para clonar e registrar os repositórios Symfony e React Native em
`/data/workspaces`. Não implemente cards de produto neste repositório de controle.

Os workflows abaixo servem como modelos nativos do Cezar e devem ser copiados ou
criados pelo editor de workflows dentro de cada repositório de aplicação.
